## Project Overview
Aura is a real-time messaging application designed to bring suspense and excitement back into digital communication. Beyond standard instant messaging, Aura introduces a completely unique feature: **"Time-Locked Vaults"**.

With Aura, you can encapsulate your message inside a digital vault and set a custom countdown timer. The recipient immediately receives the locked vault but can only reveal the hidden message when the timer strikes zero. This mechanic brings anticipation to everyday chats, perfect for surprise announcements, timed reveals, or just fun interactions.

## Core Features
*   **Real-time Messaging:** Lightning-fast messaging powered by Firebase Firestore.
*   **User Authentication:** Secure Email/Password login and auto sign-up profiling via Firebase Auth.
*   **Time-Locked Vaults (Unique Feature):** Send messages that dynamically lock themselves and display a glowing countdown timer, preventing access until the exact unlock time is reached. The UI recalculates in real-time.
*   **Presence & Discovery:** A 'Hub' that automatically detects and displays uniquely registered contacts in real-time.
*   **Modern Aesthetics:** Deep-dark mode styling, providing a premium visual experience.

## Setup Instructions
1.  Extract the source code ZIP or clone the repository.
2.  Open the project directory in WebStorm or Android Studio.
3.  Ensure your `google-services.json` is correctly placed inside `android/app/`.
4.  Run `flutter pub get` in the terminal to install dependencies.
5.  Run the application using `flutter run` on an emulator or physical device.
